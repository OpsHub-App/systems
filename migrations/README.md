## What Is OMM?

OpsHub Migration Manager is a one-stop solution for all data migration needs. Unlike traditional lift-and-shift approaches that force teams to stop work, OMM's **Live++ technology** keeps both source and target systems running in parallel. Teams continue working throughout the transition — no freeze windows, no downtime.

## How Every OMM Migration Works

### Phase 1 — Discovery
OMM's Data Discovery Utility scans your source system — project scope, data volume, entity dependencies — and produces a migration plan.

### Phase 2 — Configuration
Map entity types, fields, statuses, and workflows between source and target using OMM's interface.

### Phase 3 — Pilot
Run a pilot migration on a representative project. Validate accuracy, adjust configuration.

### Phase 4 — Production
Execute the full migration. Source system remains live. Delta sync captures ongoing changes. Multiple projects migrate in parallel.

### Phase 5 — Cutover
Reconciliation report verifies completeness. Final delta sync. Teams switch to the target system with full confidence.
