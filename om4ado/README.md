# OpsHub Migrator for Azure DevOps (OM4ADO)

A purpose-built migration tool for teams adopting Microsoft Azure DevOps. Migrate from legacy ALM and DevOps platforms with full history, relationships, and data integrity preserved.

---

## What OM4ADO Does

OM4ADO handles the specific challenges of migrating to Azure DevOps: area path mapping, iteration path configuration, work item type mapping, and the nuances of Azure DevOps's data model. It is not a generic migration tool adapted for Azure DevOps. It was built for this target from the start.
