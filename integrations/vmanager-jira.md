## Overview

Verisium Manager (formerly Cadence vManager) is a verification management platform used in semiconductor and hardware design for tracking verification progress, coverage metrics, and test results. When verification teams work in vManager and development teams track issues in Jira, connecting both systems ensures defects and verification data flow seamlessly.

OpsHub Integration Manager connects vManager and Jira with **bi-directional synchronization** — so verification data, defects, and requirements sync automatically while maintaining full lifecycle traceability.

## Why Integrate vManager with Jira?

| Challenge Without Integration | With OpsHub Integration |
|---|---|
| Defects found in verification are manually entered in Jira | Defects auto-sync to Jira with full test context |
| Verification status is invisible to development teams | Pass/fail status and coverage data sync to Jira |
| Trace links between requirements and tests are manual | Trace links maintained automatically across both systems |
| Audit evidence requires manual collection | Audit-ready traceability logging all changes and access |
| Context is lost when defects cross system boundaries | Full verification context flows with every synced item |

## What Gets Synced

**Core Entities:**
- Verification data and test results (vManager) ↔ Issues, bugs, tasks (Jira)
- Defects and requirements
- Pass/fail status, coverage percentages, and grades

**Rich Data:**
- Grade breakdowns and coverage reports
- Comments with original author and timestamps
- Attachments and linked records
- Custom fields and field mappings

**Relationships:**
- Trace links between requirements, sections, and results
- Defect-to-test associations
- Requirement-to-verification coverage

## Use Cases

**Semiconductor Verification**
A chip design team runs verification tests in vManager. Defects found during simulation auto-sync to Jira where RTL designers fix them. Fix status flows back to vManager, closing the verification loop.

**Coverage Tracking**
Verification managers need to track coverage metrics alongside development progress. OpsHub syncs coverage data from vManager to linked Jira issues, giving everyone a unified view.

**Compliance and Audit**
Hardware teams need audit-ready traceability from requirements to verification results. OpsHub maintains trace links across both systems with full change logging.
