## Overview

Tricentis qTest is a test management platform used by QA teams for managing test cases, test runs, and defect tracking. When QA works in qTest and development works in Jira, defects get logged in one system but are invisible in the other — creating blind spots in release readiness.

OpsHub Integration Manager connects qTest and Jira with **no-code, bi-directional synchronization** — so defects, requirements, and test data flow automatically between both platforms.

## Why Integrate qTest with Jira?

| Challenge Without Integration | With OpsHub Integration |
|---|---|
| Defects logged in qTest must be manually entered in Jira | Defects auto-sync to Jira with full test context |
| Developers can't see test results without switching tools | Test execution results sync to linked Jira issues |
| Release readiness requires manual data collection | Release and test cycle data flows automatically |
| Test coverage gaps are hard to identify | Requirements-to-test traceability across both systems |
| QA status meetings rely on stale spreadsheets | Real-time sync keeps both systems current |

## What Gets Synced

**Core Entities:**
- Defects, requirements, and test cases (qTest) ↔ Issues, bugs, stories (Jira)
- Test runs, test cycles, and test suites
- Releases, modules, and builds

**Rich Data:**
- Comments with original author and timestamps
- Attachments, mentions, links, and images
- Custom fields and field mappings

**Relationships:**
- Test-to-defect links
- Requirement-to-test coverage
- Release-to-test-cycle associations

## Use Cases

**Defect Escalation**
A QA engineer discovers a critical bug during test execution in qTest. The defect auto-syncs to Jira as a high-priority bug with full test steps and screenshots attached. Developers fix it in Jira, and the resolution syncs back to qTest.

**Release Readiness Dashboard**
Product managers need a single view of test progress. With OpsHub, test execution results from qTest sync to Jira, so release status is visible to everyone without switching between tools.

**Quality Progress Tracking**
QA leads track test pass/fail rates in qTest while development managers track sprint progress in Jira. OpsHub keeps both views consistent and current.
