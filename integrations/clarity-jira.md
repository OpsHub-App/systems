# Clarity ↔ Jira Integration

## Overview

Portfolio managers work in Clarity to manage projects, resources, and investments. Development teams execute in Jira. Without integration, project status in Clarity is always behind — managers make decisions on stale data while developers duplicate status updates across systems.

OpsHub Integration Manager connects Clarity and Jira with **bi-directional synchronization** — so project plans, tasks, and progress flow automatically between portfolio management and development execution.

## Why Integrate Clarity with Jira?

| Challenge Without Integration | With OpsHub Integration |
|---|---|
| Project status manually updated in Clarity | Jira progress auto-syncs to Clarity projects |
| Resource allocation based on stale data | Real-time visibility into team capacity and progress |
| Tasks duplicated across both systems | Data entered once, synced everywhere |
| Portfolio decisions made on incomplete information | Live project data from Jira informs portfolio decisions |

## What Gets Synced

**Core Entities:**
- Projects, tasks, to-dos, and investments (Clarity) ↔ Issues, epics, stories, tasks (Jira)
- Resource assignments and allocations
- Statuses and milestone tracking

**Rich Data:**
- Comments and notes
- Custom fields and attributes
- Time tracking and effort data
- Financial and investment data

## Use Cases

**Portfolio-to-Execution Alignment**
Portfolio managers in Clarity define strategic initiatives. These sync to Jira as epics and stories. Sprint progress flows back to Clarity, keeping the portfolio view current.

**Resource Planning**
Clarity tracks resource capacity across the portfolio. Jira shows actual team workload. The integration keeps both views aligned so managers allocate resources based on real data.
