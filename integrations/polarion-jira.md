## Overview

Siemens Polarion is an application lifecycle management (ALM) platform used in automotive, aerospace, and medical device industries for requirements management, test management, and change tracking. When systems engineering works in Polarion and software development works in Jira, keeping requirements and work items aligned is critical for compliance.

OpsHub Integration Manager connects Polarion and Jira with **no-code, bi-directional synchronization** — maintaining full traceability, rich data sync, and consistent data across both platforms.

## Why Integrate Polarion with Jira?

| Challenge Without Integration | With OpsHub Integration |
|---|---|
| Requirements in Polarion are manually copied to Jira | Requirements auto-sync as Jira stories or tasks |
| Implementation status is invisible in Polarion | Jira progress flows back to Polarion in real time |
| Deleted or archived items create orphaned records | Delete sync keeps both systems aligned |
| Traceability breaks between requirements and code | End-to-end traceability maintained automatically |
| Compliance evidence requires manual collection | Audit trail preserved across both systems |

## What Gets Synced

**Core Entities:**
- Requirements, stories, epics, tasks, and test cases (Polarion) ↔ Issues, stories, bugs, tasks (Jira)
- Releases, custom work items, and change requests
- Deleted artifacts synced to prevent orphaned records

**Rich Data:**
- Comments, transitions, and inline content
- Attachments, links, and relationships
- Custom fields and field mappings

**Relationships:**
- Requirement-to-implementation traceability
- Cross-entity links and dependencies
- Parent-child hierarchies

## Use Cases

**Automotive ASPICE Compliance**
An automotive OEM tracks requirements in Polarion for ASPICE compliance. Requirements sync to Jira where software teams implement them. Completion status and test results flow back to Polarion, maintaining the traceability matrix for audits.

**Medical Device Development**
A medical device company uses Polarion for IEC 62304 compliance. Requirements auto-sync to Jira for development, and implementation status syncs back — ensuring full lifecycle traceability without manual effort.

**Cross-Tool Alignment**
Systems teams manage the full product lifecycle in Polarion while Agile development teams sprint in Jira. OpsHub keeps both views consistent without duplicate data entry.
