# IBM DOORS ↔ Jira Integration

## Overview

In regulated industries — aerospace, defense, automotive, medical devices — requirements in IBM DOORS must trace to development work in Jira. Without integration, teams maintain traceability manually through spreadsheets, emails, and status meetings. This is error-prone, audit-risky, and slow.

OpsHub Integration Manager connects IBM DOORS and Jira with **bi-directional, real-time synchronization** — so requirements, change requests, and traceability links flow automatically between systems, maintaining compliance without manual overhead.

## Why Integrate IBM DOORS with Jira?

| Challenge Without Integration | With OpsHub Integration |
|---|---|
| Manual traceability matrices in spreadsheets | Automated traceability links between DOORS and Jira |
| Requirements changes not reflected in dev backlog | Changes sync bi-directionally in real time |
| Audit preparation takes weeks | Always-current traceability for instant audit readiness |
| Compliance gaps due to stale data | Continuous sync eliminates data staleness |
| Teams work in silos with no shared visibility | Unified view across requirements and development |

## What Gets Synced

**Core Entities:**
- Requirements and modules (DOORS) ↔ Issues, stories, tasks (Jira)
- Object attributes and custom fields
- Statuses and workflow transitions

**Rich Data:**
- Comments and discussions
- Attachments and embedded images
- DOORS object attributes mapped to Jira custom fields
- Module structure and hierarchy

**Traceability:**
- Requirement-to-issue links
- Parent/child relationships
- Cross-module and cross-project traceability
- Suspect links for change impact analysis

## Use Cases

**Aerospace & Defense Compliance**
DO-178C and DO-254 require full requirements traceability. OpsHub maintains live traceability links between DOORS requirements and Jira development tasks — auditors see a complete chain without manual compilation.

**Automotive Safety (ISO 26262)**
Safety requirements in DOORS trace to implementation tasks in Jira. When a requirement changes, the linked Jira items are flagged automatically for review.

**Medical Device Development (IEC 62304)**
Design inputs in DOORS sync to Jira for implementation tracking. Every change is captured for regulatory submission documentation.
