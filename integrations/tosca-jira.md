## Overview

Test automation teams using Tricentis Tosca and development teams on Jira need a seamless connection between test execution and development workflows. Without integration, test results sit in Tosca while developers work blind in Jira — defects are reported late, test coverage is unclear, and release confidence suffers.

OpsHub Integration Manager connects Tosca and Jira with **no-code, bi-directional synchronization** — so test results drive development priorities and bug fixes are validated automatically.

## Why Integrate Tosca with Jira?

| Challenge Without Integration | With OpsHub Integration |
|---|---|
| Test failures manually reported as Jira bugs | Failed tests auto-create Jira issues with full context |
| Developers don't see test coverage status | Test execution results visible in Jira |
| Manual defect tracking across systems | Defects sync bi-directionally in real time |
| Release decisions without test data | Live test status informs release readiness |

## What Gets Synced

**Core Entities:**
- Test cases, execution lists, and results (Tosca) ↔ Issues, bugs, tasks (Jira)
- Defects created from test failures
- Priorities and statuses

**Rich Data:**
- Test execution results with pass/fail status
- Comments and defect descriptions
- Attachments and screenshots
- Custom fields

## Use Cases

**Continuous Testing Pipeline**
Tosca runs automated tests nightly. Failed tests auto-create Jira bugs with execution details. Developers fix the issue, and the next test run validates the fix — all without manual intervention.

**Enterprise Test Management**
Large organizations with hundreds of Tosca test cases keep Jira in sync for cross-team visibility. Product owners see test health alongside development progress.
