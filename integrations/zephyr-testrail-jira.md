## Overview

Zephyr for Jira and TestRail are both popular test management tools. When some QA teams use Zephyr (inside Jira) and others use TestRail, test data gets siloed — making it hard to get a unified view of quality across the organization.

OpsHub Integration Manager connects Zephyr for Jira and TestRail with **no-code, bi-directional synchronization** — so test cases, test runs, and execution results stay aligned across both platforms.

## Why Integrate Zephyr with TestRail?

| Challenge Without Integration | With OpsHub Integration |
|---|---|
| Test cases exist in two tools with no connection | Test cases sync bi-directionally in real time |
| Test execution results are fragmented | Results sync automatically across both platforms |
| QA managers can't see unified quality metrics | Unified test data across Zephyr and TestRail |
| Teams manually copy test data between tools | No manual data entry — everything auto-syncs |
| Folder structures and organization differ | Sections, suites, and folders preserved during sync |

## What Gets Synced

**Core Entities:**
- Test cases, test cycles, and test executions (Zephyr) ↔ Test cases, test runs, and test suites (TestRail)
- Sections, milestones, and folders
- Test results and execution status

**Rich Data:**
- Comments with original author and timestamps
- Attachments and inline content
- Relationships and linked records
- User mappings (via email or Excel upload)
- Custom fields and field mappings

**Relationships:**
- Test-to-suite associations
- Milestone-to-test-cycle links
- Folder structure and hierarchy

## Use Cases

**Unified Test Management**
An organization acquires a company that uses TestRail while the parent uses Zephyr in Jira. OpsHub syncs test data between both tools so QA managers see a complete picture of quality without forcing teams to switch tools.

**End-to-End Traceability**
QA teams need to link requirements to test cases to defects across both platforms. OpsHub maintains these links automatically, providing full traceability for compliance and audits.

**Accelerated Release Cycles**
Instead of waiting for manual test data consolidation before releases, OpsHub keeps test results synchronized in real time — so release decisions are based on current data.
